# 🚀 React + Webpack Проект

Этот проект использует Webpack для сборки и публикации React-приложения на GitHub Pages.

## 📦 Установка

```bash
npm install
```

---

## 🧪 Режим разработки

```bash
npm run dev
```

Приложение откроется на [`http://localhost:3000`](http://localhost:3000)

---

## 🛠 Сборка Production

```bash
npm run build
```

Готовая сборка появится в папке `dist/`.

---

## 📜 Скрипты

| Скрипт           | Назначение                            |
| ---------------- | ------------------------------------- |
| `npm run dev`    | Запуск проекта в режиме разработки    |
| `npm run build`  | Сборка production-версии              |
| `npm start`      | Запуск production-сборки (если нужно) |
| `npm run deploy` | Деплой на GitHub Pages                |

---

## 🛠 Используемые технологии

- React
- Webpack
- Babel
- GitHub Pages
